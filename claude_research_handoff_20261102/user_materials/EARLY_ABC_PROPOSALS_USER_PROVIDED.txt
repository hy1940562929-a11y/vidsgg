0. 设计之前，有两件事会影响方案和论文叙事
(1) S_alone 的高召回，很可能来自"直接输出整个共现窗口"。
S_alone 的条件是 L_co ≤ 3s、L_gt ≤ 2s。在这个切片里，只要输出整个共现窗口，tIoU 就经常能超过 0.5。你们的 ρ 曲线也支持这一点：ρ∈[1,2) 时召回 0.966，median R 只有 1.01。

所以 −35pp 断崖更准确的说法可能是：模型其实从来没有做过时序定位，它只是输出共现窗口；当共现窗口恰好等于关系区间时，结果就对了。 协变量匹配控制了谓词和时长，但没有控制"轨迹边界免费提供了关系边界"这个因素。

建议在 CPU 上花几分钟跑一个基线：每个 GT 谓词都直接预测整个共现窗口，看它在 S_alone 和 S_C 上的召回。如果它在 S_alone 上接近 39–50%，论文的说法应该改为"现有方法缺少共现内部的定位能力"，而不是"长共现破坏了原本存在的能力"。这个改法更准确，也更容易被审稿人接受。它还说明，"把长窗口切成短窗口再检测"这类方案没有前途：切窗本身会制造假边界。

(2) 自己的数据不支持"短关系表现为局部相对运动"这个假设。
KTA 的 S1 结果显示，相对运动变化点命中 GT 边界的比例是 72.5%，随机放置是 72.1%，几乎一样。所以框级运动学信号不携带边界信息。如果短关系的证据存在，它更可能在外观和交互区域里（手部、接触区域、头部朝向），而不在轨迹框的运动里。这会直接影响下面方案 B 的设计。

2. 三套方案
方案 A：实例化时序解码（先定位、再定宽、模式寻优）
适用于 E1 中心命中率 ≥ 50% 的情况。属于 B2B 路线，但重新组织为一个更清楚的架构。

核心思想：把语义和时序拆开来解开死锁，把 mask 换成"点 + 宽度"的实例表示，把边际损失换成模式寻优损失。

模块与数据流

对级谓词存在头（MIL）：对 pair 特征序列 e_{1:T} 用 LSE 或 top-k 池化，输出多标签 P(π 至少出现一次)。不需要先有区间，所以不会被 90% 的静态帧稀释，这样就切断了"语义依赖区间"那一半死锁。
谓词条件的中心强度场：对每个存在概率高的 π，计算 λ_t^π = softplus(MLP([e_t; w_π]))，作为事件中心的点过程强度。∑_t λ 的期望就是事件数，所以可以自然处理重复发生。
峰值处的局部定宽：在每个峰 t̂ 附近 ±r 范围内做可变形采样，回归 log L̂ 和边界偏移。宽度来自局部特征，不使用谓词时长先验（避开 SoftMaxDur 和中位时长这两个已失败的方向）。
预算联合选择：从峰值实例和原生 K=9 候选里联合选出 9 个，目标是期望命中。P2 已经说明只需要回收一个槽位。

方案 B：共现基线残差表征 + 对内困难负样本对比
适用于 E1 < 25% 的情况（证据不足，需要新特征）。这是最有机会成为方法贡献的一套。

核心思想：共现捷径本质上是"pair 恒定的直流分量"。我们显式地去掉这个直流分量，并且只用同一 pair 共现期内的其他帧做负样本，让模型只能依靠"此刻和本 pair 其余时间有什么不同"来定位。

后一项是把当前帧内容替换成 pair 均值后的反事实输出，代表"仅凭共现就会给出的响应"。这对应 Tang 等人 CVPR'20 在静态 SGG 中的 TDE，我们的新意是把它用到时间轴上：去偏的对象是"时间位置"，而不是类别频率。
2. ρ 干预增强 do(L_co)：从同一个 pair 的非关系帧中截取片段，拼接到短共现样本两侧（或在特征层面插值延长），构造"同一事件、不同 ρ"的成对样本。加一个等变一致性损失，要求事件中心和宽度不随拼接长度变化。注意：拼接必须使用同 pair 的帧，否则模型会学到"拼接边界"这个新捷径。
3. （可选）对象/背景捷径分支：类似 RUBi，用一个只输入共现掩码和 pair 外观的分支专门吸收捷径，主分支用残差来训练。

对难点：难点 2 从因果上处理。实验设计可以和你们的 S_C^L / S_C^noL 切片、协变量匹配完全对齐，叙事最顺。

风险：如果第 0 节的猜测成立（S_alone 依赖轨迹边界），拼接后的样本会失去"免费边界"，等变一致性约束的其实是方案 B 里的证据。因此 C 的效果上限受 E1 限制，不能单独救场。
