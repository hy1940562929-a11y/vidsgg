# 完整起止边界架构图

日期：2026-10-30。性质：**DESIGN_ONLY / UNVERIFIED**。本次只修改绘图；未实现或运行新模型。

## 与用户方案的对应

1. **输入与 BSA 保留**：输入视频经跟踪和冻结 RoI 特征提取得到主体/客体外观与几何特征，原始特征直接进入 BSA。相邻帧差分画为独立的蓝色虚线可选支路，作为附加输入，不替换原始外观特征。
2. **多尺度与查询路径保留**：BSA 后保留多尺度时间编码器、Temporal FPN、9 个关系 query 及关系解码器。保留结构不等于本图已经决定整个主干是否冻结；实际可训练参数需由实验协议确定。
3. **分类与粗 mask 保留**：query 表征仍用于谓词分类；粗 mask 接收 query 与 FPN 时间特征，作为辅助监督。粗 mask 没有连接到最终区间解码器，不再以阈值后的 first–last hull 定义输出区间。
4. **新增边界读出**：query 表征与 FPN 时间特征交互，分别输出合法时间坐标上的起点、终点分布。图选择 softmax 分布及对应端点监督这一具体版本，未同时混入多个互斥实现。
5. **软时长先验**：只用训练事件拟合总体/谓词条件时长分布。推理时由模型预测谓词选择对应先验，不用 GT 谓词或“该样例属于短关系”的 GT 标记。保留全时长支持，不硬编码某个谓词只能短或只能长。`L_duration` 表示训练先验参数的时长拟合目标；若采用固定统计先验，该项不应冒称主干训练损失。
6. **有序联合解码**：

   `S_k(i,j) = log p_start^k(i) + log p_end^k(j) + λ log p_L(j-i | predicted_predicate)`

   在合法坐标及 `i<j` 约束下联合选择起止，输出 `[i*,j*)`。保持最终候选数量和排序预算，以便与原系统对照。背景 query 仍由原分类逻辑处理，不强制全部成为前景事件。

## 绘图中明确的两项修正

- 不使用两个独立 argmax，以避免终点早于起点；输出由联合得分及合法性约束决定。
- 起止头每 query 输出一个连续区间，不能自动表示其内部任意空洞；多次重复事件仍需不同 query/实例分别承载。本图不承诺“所有内部空洞不再桥接”，也不承诺长关系零损失。

时间坐标应按原采样位置与实际帧号映射，不能把头输出的位置数描述成新增视觉帧。最短长度过滤、背景类别、谓词候选数及 TopK 规则须在后续实验合同中明确。
