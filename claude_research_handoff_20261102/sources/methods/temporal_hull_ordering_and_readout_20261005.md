# 时间区间为何可能在点级响应良好时仍失败

2026-10-05，Innovation Agent 数学分析，Commander 整合。**数学推导，不是新实验结果。** 019尚未运行；不能把以下任一机制预先归给015的全部520条不可达GT。当前不进入新架构设计。

## 1. 阈值 hull 的精确约束

在固定有效采样网格上，某query的分数为 z(t)，激活规则为 z(t)>τ。希望激活集合的最左、最右点恰为a和b，即采样索引hull I=[a,b+1)。存在这样的阈值，当且仅当：

`max_{t outside I} z(t) < min(z(a), z(b))`。

证明：所有段外点必须≤τ，两个端点必须>τ；中间点是否激活不影响hull。空外集的最大值按−∞处理，精确同分不能被阈值拆开。实际帧跨度还必须满足原stride映射、最短长度和合法区间规则。

因此，对每个合法且与GT的纯时间IoU≥0.5的网格区间，如果所有query都不满足上述不等式，则该GT无法由当前阈值hull族覆盖。该条件是分数排序与位置的性质，不能仅凭不可达计数判定是背景、记忆、特征缺失或训练问题。

## 2. 点级AUROC与区间质量不同

AUROC比较随机标注点与未标注点的响应顺序；hull由极端点及其距离决定。设事件内所有点分数为1，远处仅一个段外点分数为2，其余段外点为0，则AUROC为 `1−1/N_out`，可非常接近1。但阈值只能选出远点、事件加远点或整段序列，hull仍可能与事件几乎不重叠。

这是构造的数学反例，不是本项目测得的样例。反过来，平坦响应、端点分数不足、不同事件被同一query共同激活，也可能造成不可达。因此019的点级对齐通过，仍不能直接证明区间定位已解决；对齐不通过也不能断言所有query没有时间信息。

上述推导对应纯时间IoU。官方subject/object vIoU还涉及框面积和空间误差，不能把等式直接当作native关系检测的完整条件。

## 3. 后续可考虑的最小检验，尚未批准执行

若019证据支持继续，可检查“少数远处极值是否足以解释一部分不可达”：固定raw和网格，逐query诊断性移除GT外最高的0、1、2个采样点，重算阈值hull上界，记录恢复、损失、移除点距离及是否落在其他同谓词事件中。必须对位置null执行同一GT辅助操作，防止把oracle自由度当作语义证据；不能将其他合法事件的响应直接叫噪声。

这使用GT选择要移除的位置，是机制诊断而非可部署推理。若低预算恢复不超过位置null，或需大量删点，不能支持“少数极值掩盖了有效局部事件”的解释。具体规模、来源与计算预算还未冻结，不生成实验Evidence。

## 4. 可核查的末端计算分解

源码 `analysis/vrdone_architecture_010/training_preflight/source_snapshot/models/predictor.py` 显示最终有效点的sigmoid前mask logit为query嵌入与时间特征的点积：`m=eᵀf`。在相同采样网格和有效mask下，两次前向之间满足：

`Δm = (Δe)ᵀf + eᵀ(Δf) + (Δe)ᵀ(Δf)`。

这可将变化定位到最终读出的query一侧、时间特征一侧及交叉项。实际有限精度计算需报告重构残差。各项可能相互抵消，不应仅凭绝对值宣布哪条路径主导。

两路共享上游backbone，因此该恒等式不是独立因果效应分解；交叉重组e′f、ef′也可能离开模型自然联合分布。固定query ID不保证事件语义固定；固定目标缓存向量不保证目标FPN表示不变，缓存本身也可能已包含参考帧上下文。只有预先设计、保持目标输入/网格/padding的真实干预，才能进一步讨论段外上下文影响。
