## 最小模型M010

保留原实体输入和VrdONE主体，新增一个共享 `Conv1d(256,50,kernel_size=1)`：

```text
原轨迹对特征 -> VrdONE编码器/FPN -> F
                  |                 |
                  -> query -> G,L   -> E[p,t]：谓词时间logit
                              |          |
                              +----------+
                              |          |
                        分类残差G'   谓词条件mask L'[q,p,t]
                              |          |
                         Top6谓词 -> 原时间解码 -> 原Top200评估
```

### 一个证据图，两条残差路径

`E = Conv1d(F)`，形状 `[B,P,T]`。在有效时间位置上：

\[
w_{qt}=V_t\sigma(L_{qt}),\qquad
R_{qp}=\frac{\sum_t w_{qt}E_{pt}}{\max(\sum_t w_{qt},10^{-6})}.
\]

分类分支：

\[
G'_{qp}=G_{qp}+\beta R_{qp}\quad(p=1,\ldots,P),\qquad G'_{q0}=G_{q0}.
\]

背景logit保持不变不意味着背景softmax概率不变。先更新全部50个谓词，再选Top6；训练不受推理Top6限制。

时间分支：

\[
L'_{qpt}=L_{qt}+\alpha E_{pt}.
\]

以上相加全部发生在logit空间，不能混用sigmoid概率。只有完成修正后才sigmoid并使用原0.5阈值。不同谓词可有不同mask；当alpha为正，正/负证据分别可能扩展/收缩区间。第一版alpha、beta是无约束可学习标量，均零初始化；需报告其最终符号，若学成负值不能按正向证据融合解释。

参数数目为 `256*50+50+2=12,852`，不含原模型；这是设计参数量而非测得资源用量。新头计算量小不代表全流程训练耗时已知。

第一版冻结原主体并保持eval模式，以避免dropout改变基线。只训练E头与alpha/beta。无需缓存完整 `[B,Q,P,T]`：推理只为选中谓词实例化mask；训练按GT谓词索引计算匹配成本。空输入按原流程处理；无效/padding位置不池化、不进入损失、不被解码。

alpha=beta=0时，分类logit、选中谓词mask、排序和最终官方输出必须与基线一致。mask空/最短长度的过滤规则保持原样，不能同时放宽。

## 训练监督与匹配

每个GT实例仍为 `(p_j, m_j)`。密集目标只在同一输入实体pair内部按谓词取时间并集：

\[
Y_{pt}=\max_{j:p_j=p}m_{jt}.
\]

Y用于监督E，不能替代实例目标m_j。不同谓词可同时为正；同谓词多段之间保留间隔。沿用数据集标注约定：只有可监督位置参与，已知未知/无效处忽略。union外的负标签不等于证明视觉上绝不存在该关系。

主版本以更新输出重新计算Hungarian成本，匹配过程stop-gradient、每个query只匹配一个GT：

\[
C_{qj}=2\,\mathrm{CE}(G'_q,p_j)+2\,\mathrm{Focal}(L'_{q,p_j},m_j)+5\,\mathrm{Dice}(L'_{q,p_j},m_j).
\]

匹配后仍只对匹配的单个GT实例mask监督；未匹配query监督背景。沿用原损失系数和实例归一化、背景CE权重0.1。第一阶段只在最终decoder输出加适配头；冻结原模型的辅助层损失不提供训练梯度，不伪装为额外可学习监督。

新增局部损失首版为有效位置上的逐元素BCEWithLogits平均，固定lambda_local=1。记录每项损失尺度和有效正例比例，暂不同时引入按短时长/类别/实例重加权。若需重加权，单独登记为另一因素并匹配对照。mask focal与dice仍使用原实现。

零门控时任务损失不会给E头提供梯度，由局部BCE启动E的学习；必须检查梯度确实有限且非零，并检查alpha/beta能更新。固定原匹配pi可作后续对照，不能主版永久锁死原错误分配。

GT轨迹训练、检测轨迹推理有输入域差。优先复用原作者GT训练条件并明确报告；真实proposal训练数据就绪后再作单独域适配实验，不偷偷把更多输入或数据混进架构消融。

## 对样例特征的覆盖

| 特征 | 首版要验证的能力 | 不能据此承诺 |
|---|---|---|
| 短于3秒 | 从已有特征读出短时间谓词支持，避免对所有谓词统一收缩 | 恢复未采样到的信号、所有亚秒关系 |
| 多段同pair同谓词 | 保留实例query，对各段内有效支持作语义修正 | 新增实例槽位、自动拆开一个query内所有事件、解决>9过滤 |
| 快速相对运动 | 若原位置/运动特征已有信号，改善对变化时段的关系读出 | 修复断轨、证明快运动是独立致错原因 |
| 小目标 | 输入可行且冻结特征有证据时可能改善分类/定位 | 恢复漏检实体或损失的图像细节 |

多段关系是重要风险而非保证受益组：同谓词E包含所有事件，给多个query相加可能激活别的事件，增加串联或重复。必须保留单实例mask监督并检查此副作用。若出现该问题，应记录反例，再判断是否需要query条件证据；不事后悄悄扩大网络。

如后续优先处理输入不可行组，需要独立的检测/轨迹分支：针对已有但偏差的轨迹学习框/时序覆盖修正，针对不存在的实体对补检测候选。这需要真实检测proposal训练和必要的原图/ROI特征，是另一输入改变，不能把其提升归给M010。

## 核心对照与推进门槛

首轮冻结数据划分、训练pair、stride4、Q9、Top6、Top200、训练步数与损失：
1. 原checkpoint与零残差等价检查。
2. class-only：alpha固定0，只训练分类残差和相同E监督。
3. mask-only：beta固定0，只训练谓词mask残差和相同E监督。
4. full：两条残差均启用。

若full有正向信号，追加：
- 时间均值广播E：检验是否只是每谓词校准，而非时间分辨证据。
- 同冻结特征、相近训练预算的普通首尾残差头，以及学习全局/条件阈值。
- 后续若解冻主体，必须补同参数范围、同预算的原VrdONE微调基线。

冻结主体且alpha=beta=0时，E仅aux监督不改变任何预测，属于sanity而非有意义的昂贵性能实验。未冻结时aux-only才是额外监督控制。

报告官方mAP、R50/100/200；固定原A/B/C/D下新增/损失；全部四个重叠特征组；输入可行/不可行组；GT区间误差、连续tIoU、min-vIoU；同候选Top6/排名变化；多段串联、跨gap激活及重复query。不能只展示恢复样例。

继续训练扩展的最低门槛：训练内视频不相交dev的总体mAP提高、R100不降，目标样例有可核对净恢复。该门槛不是统计显著或投稿标准。最终必须扩到固定完整评估并跨训练随机种子检查；原835验证集已曝光，不能称未见测试。

若full不超过class-only/mask-only，时间均值可复现收益，普通修正头同效，或长关系损失抵消短关系收益，则相应机制主张不成立，保留负结果，不升级为主方法。

## 已有方法与新颖性边界

- [VrdONE §3.4及Appendix D](https://arxiv.org/html/2408.09408v2)：已有FPN、实例query、联合分类定位及semantic decoder对照。本文不能声称首次引入密集谓词时间图或联合学习。
- [BIG §3.2](https://arxiv.org/pdf/2112.04222)：已有三元组条件的多实例时间定位。
- [TSPN预印本 §III.E](https://arxiv.org/pdf/2107.07154)：已有谓词×时间存在分布。此处是保留实例分解后的辅助修正，不是换一个输出张量就构成创新。
- [TFNet公开匿名稿 §4.4–4.5](https://openreview.net/pdf?id=Hhr220TJFh)：预测区间/Gaussian注意力/逐时刻分类再pool；只核实了搜索索引中的原文片段，网页遇验证，接收状态未确认。不能称已发表ICLR论文，也不能据局部片段宣布其不存在所有类似反馈机制。
- [TCANet](https://arxiv.org/pdf/2103.13141)：局部首尾残差和时间细化已有直接先例。

可检验的区别是：同一实例query下各谓词的时间支持是否应分别调整，以及同一显式谓词时间证据参与两项预测是否超过普通分类/定位校准。有效性、必要性与新颖性都尚未成立。
