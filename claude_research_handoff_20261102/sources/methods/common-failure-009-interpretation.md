# 009：从可复核错误到方法能力边界

这是 Commander 对已导入 009 证据的解释。实际运行和数字见 incoming009/REPORT.md；数学推导不是额外实验。全量835结果随后已返回：R4救回64条固定C，却在所有GT上新增78、损失108，净−30，总体改进未成立。以下局部数学机制不能推出全量收益。

## 三个不能互相代替的问题

1. **输入是否允许匹配？** 固定 C 中16,828/25,373条在当前 VrdONE 合格输入对上不可行。若保持这些输入框、类别和轨迹不变，仅改变关系分数或时间区间不能恢复它们。该结论不覆盖 BIG 输入，也不说明原视频不可识别。
2. **正确候选是否被表示？** 旧32的可行 C 中，180条没有匹配的原始时间跨度，26条匹配跨度对应的正确谓词不在Top6。前者仍混合采样、mask学习、解码和几何匹配因素；不能直接命名为历史干扰。
3. **已有候选是否得到输出名额和匹配？** 旧32有120条可行 C 已有正确原始候选而未在Top100匹配。R1/R2的同候选复核展示了实际排序恢复，但R2也损害原有关系。存在候选不等于能同时召回全部GT。

32视频各比例不能直接外推到全体C。短时长、小目标、重复GT记录是重叠特征，前述三项是针对给定处理链的能力问题。

## 时间裁剪何时帮助，何时损害

令固定实体轨迹的预测管道为P，GT管道为G。以各帧框面积累加定义体积，I=|P∩G|，U=|P∪G|，原vIoU为I/U。提高mask阈值后区间嵌套为P'⊆P。设裁掉的预测体积中，O位于G之外，J与G重合，则：

\[
\operatorname{vIoU}(P',G)=\frac{I-J}{U-O}.
\]

这里令D=P\P'，J=|D∩G|，O=|D\G|。O包含GT时间内空间不重叠的删去体积，不能用事后脚本的“GT外时间跨度”代替。在有效非零分母下，改善当且仅当 IO>UJ；若O>0，可写成J/O<I/U。即删掉错误支持的收益，必须超过删掉正确重叠的代价。若O=0且J>0，则严格下降。官方关系匹配取主体与客体vIoU的较小值，必须分别考察二者；单条时间轴不能代替几何检查。

R4通过提高统一阈值来做这种裁剪，不能独立扩展某一侧边界。因此它既能修复 child–watch–toy 的过宽支持，也会丢掉 adult–watch–laptop 的有效支持。已观测到“mask均值上升但vIoU下降”的同候选反例；平均置信度是模型自身分数，不能用作定位正确性的保证。

## 为什么短关系值得检查，但不能直接称为原因

在完全正确且面积恒定的空间框这一简化条件下，若GT时长为d，预测向两端各多出ε，则时间IoU为d/(d+2ε)。同样的绝对边界误差对更短关系有更大的相对影响。固定采样和最小长度约束可能进一步限制可表达区间。

这只是评估敏感度的数学解释，不是“短时长导致本项目失败”的实验结论。现有分层比较支持短时长仍与漏检相关，但尚未区分感知、采样、监督与排序，更未验证实体交互或参与者切换。小范围干预仍没有改善亚秒组。

## 有证据支持的下一步与停止条件

- 冻结R4的全量评估已完成：C恢复64、D恢复14，A损40、B损68；严格<3秒净+16、≥3秒净−46。已如实保留负结果，没有改门槛重选方案。统一0.75阈值不推进为默认方法。
- 对全部发生Top100变化的GT复核同一候选的区间、排名、分数及vIoU，同时报告时间覆盖和过伸。该分析发生在预测之后，不参与输出或阈值选择。
- 若定位误差仍值得优化，训练时需要允许保留、收缩及扩展边界，且将原本正确的候选纳入训练和损失统计。一个独立首尾残差头可作常规基线；CBR、TCANet、BIG已有相关机制，不把简单头宣称为新贡献。
- 真正训练之前必须找到训练标注及相容的输入特征，划分视频不相交的开发集。当前只有可用验证链，不能用验证错误标签拟合后又在同集报告模型提升。
- 只有超过固定阈值、学习全局阈值和条件阈值等简单对照，且目标样例收益能够复核、原有关系退化可接受，才考虑进一步方法设计。是否成为论文主方向由用户决定。
