# E099-GRADIENT-ROUTING：唯一决定性实验合同

日期：2026-10-20。**DESIGN_ONLY / NOT_RUN / NOT_QUEUED**。对应[H099](CAUSE_STATEMENT.md)。

唯一操纵：**分类梯度进入共享decoder/query时的方向处理**。不改前向结构、attention归一化、时间网格、候选数或loss。不是E091/E097/E098的重跑。

## 1. 固定三臂与零更新参照

θ为原predictor中decoder、query embedding及其输入norm/projection的共享参数；分类头、mask embedding为私有参数。encoder、FPN与实体输入冻结。用原criterion分别求所有辅助层及末层的加权分类损失Lc、mask损失Lm，然后在θ上求c、m；**先聚合再投影一次**。

| 臂 | 进入θ的梯度 | 排除什么替代解释 |
|---|---|---|
| O | \(m+c\) | 原联合更新，同预算对照 |
| P | \(m+c_P\)；只移除c中与m冲突的分量 | 定向去除任务冲突 |
| W | \(m+\alpha c\)，\(\alpha=\|c_P\|/\|c\|\) | 同等分类梯度范数缩减，保留原方向 |
| C0 | 原预训练模型，零更新 | 排除只胜过变差续训对照 |

\[
c_P=c-\frac{\min(c^\top m,0)}{\|m\|^2}m.
\]

当m=0，取cP=c；c=0时W分类分量为0。范数和内积用float64累加计算系数；参数与原生前向仍float32。正内积时O/P/W更新相同。各臂私有头照原loss正常更新，不对其梯度做投影。P/W仅保证**在同一参数状态下**分类分量范数一致；各自训练轨迹分叉后不得声称跨臂实际梯度范数一直相等。总更新范数不强行统一，实际范数、clip系数和AdamW步长全部记录。

该操作接近已有PCGrad，是**原因检验工具，不是宣称新发明的算法**。未来架构不在本实验中训练。

## 4. 同一实验内的机制测量：不是另开配方

### 4.1 原生状态与训练中的梯度账

在C0及O的第250、500步，使用固定88个train批次，逐批记录c、m范数与夹角；另拆出短GT（<3s）和长GT（≥3s）的事件mask梯度，只用于测量，不用于P的投影。包含背景的Lc保持原定义，不挑冲突batch。

mask分解必须包括原target及辅助层；按事件记录损失，不能把长视频/多事件批次当作更多独立实验。短/长梯度存在性、零梯度、目标数、当前匹配及梯度占比入账。负内积比例、梯度角度只作通路证据，不单独触发VERIFIED。

### 4.2 从相同O状态出发的一步反事实

在上述三个固定状态，分别对每个train batch克隆模型、**完整AdamW状态、RNG和相同当前Hungarian匹配**，做一次O/P/W虚拟更新，随后恢复原状态。虚拟步三条件共同使用该O状态的原全局clip系数；私有头使用相同梯度和Adam状态，须逐参数核验其更新相同。这样有限步差异仅从共享θ的梯度处理进入，不被不同clip系数下的私有头步长混淆。O虚拟步等于实际O算法；P/W虚拟步是固定clip的受控探针，实际P/W训练仍按各自完整梯度做原生全局clip。候选训练轨迹不吸收这一步更新；它不是新增训练臂或checkpoint选择。

对固定dev全部事件测量更新前后loss；评价dev事件采用更新前由原Hungarian选出的同一query，更新后不重新选最佳query。无匹配的事件列缺失账，不用GT时间另选query；三个状态以C0预先确定的dev事件支持作共同分母，后续匹配缺失仍记录，不能择优保留。dev标签只用于测量，不形成更新梯度、选步长或挑样本。每个event损失按同一原生focal/Dice定义单列：

\[
d_e(O,P)=\frac{L_e(\theta_O^+)-L_e(\theta_P^+)}
                  {\max(L_e(\theta),10^{-8})}.
\]

同理报告d(O,W)、d(W,P)、各臂相对零更新的绝对损失变化。正d(O,P)表示定向去冲突比原更新更利于该事件；**不等于原更新本身使loss上升**。虚拟步共享clip系数、私有头delta、共享θ实际delta逐项归档；真实训练中的clip差异另记。W及第7节预测结果用于避免仅凭有限步数字归因，结论限于梯度路由的操作性效应，不是纯角度定理。

88个train方向先在每个dev事件内平均，再按dev视频等权；bootstrap以dev视频为簇，不能把88次虚拟步当88份独立dev数据。

短组特异性：只用dev中同时含短、长事件的同谓词支持；谓词内先算短/长事件平均d，再每视频平均共同谓词，再视频等权。无该支持的视频不补造；要求至少4个视频、短/长各至少20事件，否则`REJECT / SHORT_SPECIFICITY_UNIDENTIFIABLE`。全部dev结果仍报告，不能只展示共同支持。

VERIFIED须在**C0状态**满足：短组d(O,P)、d(W,P)的95%CI下界>0；短−长d(O,P)差的CI下界>0，且短组的 \(c_b^\top\nabla_\theta L_{{dev},e}\) 在88个train方向、事件、视频按相同层级平均后为负。dev梯度仅用于这一测量，绝不交给优化器。250/500步同口径完整报告，不选择最优状态替代C0。若只后期出现，最多证明续训新产生的冲突，本合同不接纳为原残余的原因证据。

这仍是有限步局部机制。没有原预训练轨迹，不能反推原训练历史。

## 5. 前向封存、评价与支持

保持E098共同9-slot协议：每个固定pair一次前向、9个mask；`sigmoid>0.5`取首末正点hull，stride4末点+1，min5；当前无合法输出则空。不加query、不拆hull、不调整阈值，不根据GT谓词/时间选择query。

先封存9条原始mask与全部类别概率、所有区间，再连接GT：

- **时间形状**：固定pair内tIoU≥0.5，先最大一对一命中数、再最大总tIoU、再GT ID/query索引字典序；各组独立匹配，全2573另作一次完整匹配。组间不可相加。
- **类别一致**：每query对包括背景的全类argmax，tie按类别ID；背景为空；前景要求谓词正确和tIoU≥0.5。同一槽不能命中多条GT。不是原生Top6展开后的官方mAP/R@100。
- **分数机制**：类别无关原始mask集合 \(s(t)=\max_{q=1..9}\sigma(z_{qt})\) 的局部AUROC。评价正点为GT内，负点为左右各一倍GT时长的邻域，排除同pair任一其它GT关系的有效区间，裁于当前段。原网格取点、不插值。排除其它关系避免把合法重叠当假阳性。它不使用GT选query，仍是诊断分数而非最终检测器。
- AUROC各臂相同支持，缺正/负点必须入账；400支持少于320条或16视频则`REJECT / SCORE_MECHANISM_UNIDENTIFIABLE`，不改负点窗口。不能把缺支持事件从区间命中分母删除。
- 全2573类别一致precision分母是所涉固定pair的全部非空前景候选，pair去重；不按目标类别/GT过滤，零候选记0。

每臂/seed报告N、候选数、命中、新增、损失、净差、端点偏差及匹配ID。400与长组视频等权；334同时报原始计数和可达缺口闭合率：

\[
\eta_{P,O}=
\frac{\overline{M_P-M_O}}{U_9(334)-\overline{M_O}}.
\]

相对W、C0也同式。负值不截断；分母≤0走`REJECT / NO_RESIDUAL_HEADROOM`。bootstrap重复中分母≤0记0并报告次数，不能静默丢弃。

整视频配对bootstrap 10,000次、seed99，保留所有臂/seed配对，先三seed平均再按上述口径聚合；C0仅一份。所有支持数、CI、分子分母及bootstrap索引封存。该27视频被反复诊断使用，结果不是独立泛化估计。

## 6. 为什么不是靠新容量或普通续训赢

三臂网络、参数量、前向、原loss、query数和推理完全相同，只有共享分类梯度方向处理不同；W排除等范数缩减，O排除同预算训练，C0排除基线退化。encoder/FPN冻结，原生row-softmax不变。需实测训练额外耗时及内存，不能把额外求梯度说成计算免费。

P本身是已有梯度手术的一种定向版本；如果只显示这种通用优化器提高分数而没有第4节短事件机制链，不满足H099。训练结束后“关闭梯度手术再推理”不会改变结果，**禁止把这种无效开关写成撤回实验**；同状态的一步更新比较才是这里的操作性反事实。
