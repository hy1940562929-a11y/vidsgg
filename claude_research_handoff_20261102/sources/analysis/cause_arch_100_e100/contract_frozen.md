# E100-DEPTH-EVENT-ASSIGNMENT：唯一决定性实验合同

2026-10-20。**DESIGN_ONLY / NOT_RUN / NOT_QUEUED**。对应[H100](CAUSE_STATEMENT.md)。本轮不执行此合同。

## 1. 唯一操纵与固定三臂

原模型9个query、4层输出。令C_l(q,g)为原生第l层query q到事件g的Hungarian成本，原分类/focal/Dice系数、valid mask及归一化不变。成本不反传。

| 臂 | 对应方式 | 不变的内容 |
|---|---|---|
| N | 各层分别求Hungarian最优分配 | 原生训练对照 |
| T | 在`sum_l C_l(q,g)`上求一次Hungarian；四层物理query q监督同一事件g | 原损失、原层权重、每层匹配数 |
| X | 在`sum_l C_l(p_l(q),g)`上做同样联合匹配；第l层将g分配给物理query p_l(q) | 同T的联合优化规模与监督数量；只错开层间对应 |
| C0 | 原预训练模型，零更新 | 各臂共同参照 |

X使用q=0…8、辅助三层`p_l(q)=(q+k_l) mod 9`，k=(1,3,5)，末层k=0。映射固定，不依赖GT、数据、seed或效果；不试其他置换。**只改变成本和loss的对应，不重排forward的hidden states。** 同时重命名整网query会变成等价操作，不能代替X。

GT数量超过9时仍执行原矩形Hungarian、每层匹配min(G,9)，完整GT均保留；未分配事件入账，不能删掉或新加槽。联合分配可能改变被分配的GT子集，该下游效应单列，不能伪称所有事件均获监督。GT事件身份以原完整target ID为准，不按谓词合并。

N和T的区别只有跨层分配约束；X排查是否任意联合成本或正则化都能获益。T只胜X不支持H100。T的全层一致是定义结果，不是成功指标。

5. 可复用见证仅限当前合同的读出、保护点值和成员完全相同。核验至少存在一组≤9槽候选能使334净增≥61、400两类命中视频率提高、长组两类视频率差≥−0.01、全2573命中与类别precision不减少。它证明容量不挡住要求，不证明网络可学到；严格不可行证书才走范围拒绝，核验不成走技术出口。
6. C0全88训练批记录N/T的query-event监督是否不同：同谓词不同时间段、不同谓词、前景/背景、超过9个GT导致的目标子集变化分别计数。监督等价依据实际criterion消费的张量：当前非fuzzy路径用“谓词+valid掩码+有效网格上的target”标识；原连续GT端点不同但上述张量相同，仍是等价监督，不算有效变化。不得为制造暴露切换fuzzy设置。等价交换不删除训练标签；原事件身份与连续端点仍保存在观察账中。

**不设多数切换率或C0一步梯度收益门槛。** 若C0所有有效target对应都相同，走`REJECT / NO_INITIAL_ASSIGNMENT_EXPOSURE`停止：该操作不能检验原残余的假设；不再等待训练自行制造问题。否则继续本合同，不凭非零变化率宣称主因。最终必须报告变化涉及的事件/批/视频分子分母。

## 4. 统一推理与主终点

所有臂同原生9query、sigmoid>0.5首末正点hull、stride4末点+1、min5；不拆分、不调阈值、不按GT选query/层/类别，不扩大输出容量。先保存全部类别概率、四层mask及最终9槽区间，随后接GT评价。

- **时间形状命中**：固定pair内tIoU≥0.5，先最大一对一数量、再总tIoU、再GT ID/query索引；分别评价400、334、163、1101、全2573。不同切片独立匹配，不可相加。
- **类别一致命中**：同上且包括背景在内的全类argmax正确；背景不输出，tie按类ID。不是官方Top6类别展开后的mAP/R@100。
- **全体类别precision**：2573所涉pair去重后的全部非空前景候选为分母，不能按GT筛预测；零候选记0。
- 每臂/seed均报告N、命中、新增、损失、净差、候选数、匹配ID及端点误差；不得只报恢复。
- 400和1101用视频等权率；334主效果：

  `eta(T,K) = mean_seed(M_T−M_K) / (331−mean_seed(M_K))`，K∈{N,X,C0}。

  不截断负数；分母≤0为`REJECT / NO_RESIDUAL_HEADROOM`。对C0要求eta≥0.20意味着平均净增≥60.4条；三个seed合计至少182条，远低于新协议302条可达缺口。**不是旧合同多数334，也不是几何+5pp。** 相对N/X也执行同式。

视频配对bootstrap10000次，seed100，三训练seed先平均，所有臂保持配对；334的分子分母都按抽到的视频重建。bootstrap分母≤0的重复记eta=0并报次数，不丢弃。双侧百分位95%CI。以下条件为交集判决，不以挑选显著指标过关；CI只描述当前已反复使用群体，不宣称独立泛化。

## 5. 同一实验内的非循环机制测量

### 5.1 锁定诊断query与支持

在训练前C0，对全部dev事件用**原生末层Hungarian**固定query q0(g)。该匹配仅为诊断，不能进入推理选样或改变训练。若GT未分配，不另选最佳query，记缺失。所有臂/seed/层/训练后均观察同一物理q0，避免训练后用GT换一个更好的query。

正时间点是GT内原网格；负点取左右各一倍GT时长、裁到原连续段，并排除同pair任一其他合法GT区间。无正/负点单列；所有条件共同支持固定于C0。全dev支持均报告，机制主比较只用同视频同谓词同时有短长的共同支持，至少4视频、短长各20条；不足则`REJECT / MECHANISM_UNIDENTIFIABLE`，不缩窗或改成员。

该支持不同于099损失测量支持，不能直接把历史27短/46长当成本轮已通过。区间命中分母始终400/334/163/1101/2573，不随机制缺失缩小。

### 5.2 什么才算时间分数被改善

对每层l的固定query记录：

`m_l = mean_GT sigmoid(z_l,q0) − mean_neighbor sigmoid(z_l,q0)`，

以及原始logits的局部AUROC（ties计半）。在每个视频的共同谓词内先算事件平均、再平均谓词、再视频等权。预设主机制指标是**末层AUROC**；m_4和m_4−m_1辅助解释，防止仅第一层变差造成“深度改善”。

要求**共同支持短组**的T末层AUROC相对N/X/C0差的CI下界均>0，按短事件→共同谓词→视频依次聚合；同视频同谓词的短−长AUROC增益差（T−N）的CI下界>0；同一短组T的m_4相对N/X/C0点差均>0。全事件平均不能代替短组收益。这样不能以长组变差制造唯一正结果。另报所有层曲线，不挑中间层最大值。

同时在C0及500步输出上，对所有臂**重新按N独立匹配**，记录自然跨层事件对应变化、匹配成本余量和GT子集变化；不采用T强制分配作为这张诊断表。它们只帮助解释，切换下降本身不触发VERIFIED。共同重命名全层query不应改变这些统计。

本合同不测C0梯度去冲突收益、不增加虚拟更新或第四训练臂。固定q0可能限制对训练后重新分工的解释；若实际命中提高而q0机制不通过，走METHOD_ONLY，不为追求机制通过重选q。

## 6. 互斥判决，按顺序执行

1. **TECHNICAL_FAILURE**：材料/身份/4e−6/同源重建、原生loss接口、对应实现、冻结参数或完整预算失败；或容量见证无法核验。记录子因与实际数值，不记科学阴性。
2. **REJECT / SCOPE_NOT_TESTABLE**：严格联合容量不可行；`NO_RESIDUAL_HEADROOM`单列。
3. **REJECT / NO_INITIAL_ASSIGNMENT_EXPOSURE**：§3.6无有效C0差异；**REJECT / MECHANISM_UNIDENTIFIABLE**：§5支持不足。属于范围不可识别，不证明所有匹配机制不存在；停止，不追加实验。
4. **VERIFIED / SCOPED_DEPTH_EVENT_SUPERVISION_EFFECT**：以下全部成立：
   - 技术、容量、实际操纵、机制支持通过；500步确有参数更新。
   - 334上T相对N/X/C0的eta点值均≥0.20、CI下界均>0；每seed T−N和T−X净命中均>0。
   - 400时间形状及类别一致命中的视频率差相对N/X/C0，CI下界均>0；163完整报告。
   - §5.2末层AUROC、短特异性及末层margin全部通过。
   - 长1101两类命中视频率差相对N/X/C0的CI下界均≥−1pp；全2573两类平均命中数及类别precision相对N/X/C0均不下降。
5. **REJECT**：其余技术有效结果，依首个失败命名：
   - `INTERVENTION_INACTIVE`：T无参数更新或监督作用未实际进入训练。
   - `TRUE_PATH_NOT_BETTER`：T未稳定超过N，或仅超过故意错位的X。
   - `EFFECT_TOO_SMALL_OR_UNSTABLE`：区间/eta/跨seed门槛不过；CI跨门槛是未决而停止，CI上界低于门槛是该配方较强负证据。
   - `METHOD_ONLY_NOT_CAUSE`：区间有效但原始分数或短特异性不足。
   - `PROTECTION_FAILED`：前述通过，但长组/全体保护失败。

REJECT是停止此预算下的原因配方，不宣称所有稳定匹配无效。VERIFIED也只支持限域的监督效应，**不等于完整历史根因已识别、全val提升、正式架构采纳或CVPR创新性已成立**。
