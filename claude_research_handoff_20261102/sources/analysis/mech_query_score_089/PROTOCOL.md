# 089 冻结协议：查询选择 vs 固定分数读出的区间不足

2026-10-20。单任务，本地CPU；复用087原生mask/class logits及088已封存候选。不训练、不前向、不连接服务器，不调整阈值、分量规则、融合或gate。

## 研究问题与边界

在相同实体连续段和时间分数下，分类分数最高的query是否选错了事件？增加“首选前景谓词符合目标”的条件后，能否在相同一个query容量内改善时间形状匹配；若不能，该条件下是否仍有多数目标缺少匹配区间？

两种主读出都使用已知GT谓词和原固定pair，是条件诊断，不是无GT部署方案或原生TopK检测。原生模型可保留每query多个类别；本实验的前景Top1过滤只是明确固定的诊断条件，不把它称为原生类别准入。

## 固定输入与读出定义

- 成员：086/087/088同一400条（23视频）；亚秒163条仅作描述。
- 固定原pair_idx和legacy query。087 native_classes是9×51 logits，0为背景；谓词映射取存档category.py。概率使用全51类稳定float64 softmax，不能以目标类raw logit跨query比较。
- 预检只检查分类排序，不看089时序终点。400/400 legacy query与087固定pair内目标谓词概率argmax一致。首次草稿曾因成员gt_index字符串/整数连接得到空表，已在冻结前修正并强制N=400；空表不构成有效预检。
- F（固定读出）：使用legacy query。若执行时重核发现其不等于当前argmax，保留样本和描述结果，主判决INCONCLUSIVE_SCORE_DRIFT，不临时换基线。
- T（前景类别约束重选）：在相同pair内，保留`argmax(class_logits[q,1:])+1 == target_pid`的query；再按全51类softmax的目标谓词概率最高选一个，并列取最小query索引。没有合格query则空。该条件不要求前景概率超过背景；报告背景占优情况，不据此删样本。
- 同pair、同目标谓词复用同一F/T选择。选择器不接收GT开始/结束、时长或匹配结果。先封存完整query选择账，之后才评估GT。

## 时间成段与容量

直接复用088已封存H/C候选及其来源SHA：严格sigmoid>0.5、stride4、末点+1、min5。

H为首末正点hull。C为先移除不满5帧的连续分量，再选平均概率最高者，并列峰值、最早起点；不选择GT最佳分量。

F_H/F_C/T_H/T_C各至多一个候选，每组使用同一query选择，不因区间为空回退。报告空槽与实际数量，T不存在计全体失败。共同支持组只以“T有合格query”定义，仍保留其成段为空的失败。

U_H/U_C：固定同一pair全部9个query中任一候选tIoU≥0.5的时间存在性上界。U_union仅用于描述两库合并后的存在性；它不是同容量可部署读出，不与F/T相减冒充方法提升。088 H47/400、C53/400对应这组U，不是本轮单query基线。086历史47/400搜索同身份全部连续段，禁止与本轮固定pair混用。082读出是已保存TopK首个身份/谓词匹配候选，也不同于本轮裸分类分数选择。

## 指标与统计

主终点：400条上的C时间形状匹配率（tIoU≥0.5），对比T_C−F_C；H结果同表描述，不用于事后替代C主终点。每GT报告F/T/U匹配、tIoU、query索引、类别分数、T是否存在、空输出、增益/损失。没有正确谓词一对一预测匹配要求，不报告mAP/正式Recall提升。

推断：各视频内按该组GT数平均，再视频等权。seed89、10,000次配对视频bootstrap，所有臂在同一群体内共享抽样索引。主群体固定23视频、400GT；T存在条件组排除没有合格GT的视频，明确N及视频数，组内独立使用seed89抽样。该组T_C失败率CI也从同一组内抽样索引得到，区间采用2.5/97.5百分位。

亚秒163使用同一选择和候选库，报告分子分母、新增损失及描述率，不新增判决。各组均保留未命中。既有23诊断视频经过多轮查看，CI不是独立验证集泛化保证。

补充支持账：F_C失败中U_union也不匹配的数量及条件分母，只描述剩余空间，不新增“主要因果归因比例”。088已知346/400无H/C匹配，这部分不是089独立新证据。

## 冻结判决出口（按顺序）

1. SHA/形状/成员/固定pair/候选封存审计失败：INCONCLUSIVE / TECHNICAL_FAILURE，停止；不放宽检查。
2. legacy query与087分类排序不一致：INCONCLUSIVE_SCORE_DRIFT；不删事件、不临时换基线。
3. **SUPPORTED_QUERY_RESELECTION**：全400的C T−F视频等权差≥0.05且95%CI下界>0，同时T存在共同支持组视频等权差>0、事件新增>损失。只支持本目标谓词条件下的前景类别约束重选带来预设幅度改善，不证明原生Top6选错query的因果机制。
4. **SUPPORTED_RESIDUAL_INTERVAL_DEFICIT**：T存在组至少40GT且至少10视频；其T_C失败率视频等权95%CI下界>0.5；全400的C T−F差95%CI上界<0.05。解释为“首选前景谓词符合目标时，本固定C读出下仍多数不匹配，且本T重选未达预设明显改善”。这是用户所问“分数结构仍差”的有限操作性证据；不能区分mask生成、阈值、分量选择、表征或训练，也不证明换所有query策略都无效。
5. 其余：**INCONCLUSIVE**。不扩大样本、筛谓词、改阈值/selector或启动训练追结果。

上述支持出口不互为所有原因的排他解释；小选择收益与残余困难可同时存在。主机制仍需按可支持范围描述，不把读出失败升级为训练/架构因果。
