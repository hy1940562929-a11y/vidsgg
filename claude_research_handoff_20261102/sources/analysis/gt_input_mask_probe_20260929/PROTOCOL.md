# GT实体输入后的冻结时间掩码诊断

2026-09-29，计算结果前固定。用户已授权本次AutoDL连接及小规模冻结推理；不启动训练，不修改原代码、checkpoint、环境或数据。

目的：在正确实体框、轨迹身份及有向实体对输入下，检验现有VrdONE时间mask是否包含正确时间段。与同视频原输入比较新增、损失、净增；不将oracle诊断称为新模型性能。

范围：已有GT特征的strict27验证视频。该集合由既往参与实体切换筛选，非随机、非独立测试集。纳入这些视频的全部GT关系，不限44个切换事件或原失败样例，不外推至全部30,142条。

输入：核对已有GT proposal每帧box与annotation、tid和1024维特征与frame-key(fid+1)完全一致、连续段完整、特征有限且非全零。已找到既有GT ROI提取代码与27视频完成日志；历史日志未保存运行命令/权重哈希，无法完全重建特征提取时的环境，作为历史来源局限保留。

GT条件：只用GT主体/客体身份指定有向pair，枚举该pair所有实体连续共同存在段，保留完整共同存在时间。不给模型关系谓词、起止时间，不按关系窗口裁剪，不用训练随机裁剪。关闭预测轨迹去重，其他验证预处理、stride=4、offset=0、至少5帧/2采样点、9条query、原EMA权重不变。空间特征从GT框重新计算，视觉特征为已有GT ROI特征。

原输入：保持原验证缓存与预处理。优先复用同输入原始输出，并做一个完整视频的冻结forward一致性核验。两侧保存后处理之前每pair的9条原始mask，不采用谓词top6、类别分数、全视频Top100/200或排序。

执行核验修正（尚未读取真实评估结果）：全视频复用审计中，第26个视频1164_3804148568相对旧raw的mask最大绝对差0.00151062、logit差0.000274658，二值符号翻转0；前25个视频逐值一致。严格复用gate记FAIL并保留。主实验改为`--native-fresh`，在同一进程、同一输入缓存/权重下重新计算全部native与GT输出，使用paired27_fresh_v2评估；不放宽原复用通过条件，不混入失败历史基线。

主要可比指标：原解码mask包围区间，正点阈值sigmoid>0.5，区间为[first_sample,last_sample+1)，主口径min5。逐GT关系检查至少一个主体/客体类别符合、两条管道vIoU均>=0.5的mask；GT侧进一步限制正确身份pair。记录原输入覆盖、GT输入覆盖、新增、丢失、净增。这是输入纠正后的空间+时间候选存在性对照；差异包含几何纠正和输入表征变化，不能单独归因于mask head变好。另报不加min5口径。

纯时间指标：在GT正确身份pair上分别检查tIoU>=0.3/0.5/0.7；另把每个正采样点保持到下一采样点（最多4帧、截在pair_end），评价二值mask全视频时间IoU>=0.5，惩罚支持外的GT漏覆盖和GT外误激活。包围区间与二值mask分开，不把填平空洞的解码假设当原始mask。若有任一query达到阈值，称候选覆盖，不称自动选择正确。

补充：GT-grid理想标签解码参考值（不一定是最优上界）；另在同一采样网格的所有合法首末端点间寻找最高tIoU，得到独立的几何可表达性上界。按(video,subject_tid,object_tid,begin,end)合并仅谓词不同的时间事件，对query与事件做一对一最大匹配，避免一个mask重复命中多个时间事件。全体、时长组、原C共同失败组均报告固定分母和净变化。缺输入保留为miss。所有百分比附分子/分母。

约束：这不是实际RelDet mAP/R@100，不是训练后的提升，不是对短关系困难原因的因果证明；27视频之外的增益未知。无论结果正负均保存。
