# E098-JOINT-READING：单一决定性实验合同

日期：2026-10-20。**DESIGN_ONLY / NOT_RUN / NOT_QUEUED**。
对应唯一假设[H098](CAUSE_STATEMENT.md)，架构见[ARCHITECTURE](ARCHITECTURE.md)。本文件不是启动授权；本轮不写执行脚本、不导出缓存、不连接服务器。

## 1. 研究变量与容量合同变更

唯一自变量：decoder cross-attention的归一化算子。

| 条件 | 算子 | 用途 |
|---|---|---|
| N | 原生按时间的row-softmax | 同预算训练对照 |
| J | 同一logits上的联合行列平衡 | 修复跨query时间读取覆盖 |
| C0 | 原预训练N，零更新 | 新评价协议下的原模型参照，非第三训练臂 |

两臂均9个query、同一Q/K/V结构、同一输出头及参数量；不增加query，不加CDF/W1或任何新loss。

**选A，显式撤销旧F和原H历史准入作为主评价限制，两臂一起撤销。** 每个固定pair连续段计算一次9个mask；各mask用当前H输出至多一个区间。旧F、旧准入只保存作来源审计，不再按GT复制或锁定某一slot。阈值仍`sigmoid>0.5`、stride4末点+1、min5；不使用C、P、不搜阈值。无合法区间时为空。

原生每query还可展开多个谓词；本实验的9-slot时间形状诊断及下述Top1类别伴随指标，并非原生Top6展开后的完整官方评价。不能称为官方R@100或mAP。

公平性：N、J、C0使用完全相同的候选数上限、解码、评价匹配和分母。所有效果必须相对新协议N/C0计算；095的14/400和088的存在性覆盖47/400只能列历史口径，不是本轮增益基线。参数量相同不代表FLOPs相同，需另报归一化开销。

以095配置、094 manifest及097执行成员文件为身份依据，执行前封存SHA。成员分组包括GT辅助条件，属于条件诊断；不是独立泛化测试，也不由这27视频估计全VidOR比例。

**094 PASS不自动满足本合同。** 训练decoder需要：

1. 原生decoder输入、有效key掩码、每层真实时间坐标；原mask分支输入；完整预训练decoder/query/分类头/mask头初始化。

只有末层`hs[3]`与mask输入、087分数NPZ或旧冻结matching不够。不能用它们伪造可训练decoder。缺材料即`TECHNICAL_FAILURE / MISSING_DECODER_MATERIAL`。

在任何更新之前，N路径重建所有涉及的train/dev/eval原生logits：max abs≤4e−6、全有限、类别与二值结果一致；逐批记录实际误差、最差批次、dtype/device。失败停止，不改容差。J改变算子，**不要求J的step0与N相同**；两者权重必须相同。

## 3. 训练前容量和现象准入：同一次实验的停止门槛

### 3.1 新容量审计

按固定pair连续段分组；每组有9个可为空的槽，每槽一个合法区间，不冻结原H准入。只在诊断审计中允许GT oracle选时间，不允许其结果生成模型预测。

对每个评价集合S（400/334等分别计算），若该组有\(n^{legal}_{p,S}\)条GT各自存在可匹配的合法网格区间，则时间形状一对一的容量上界为：

\[
U_9(S)=\sum_p\min(9,n^{legal}_{p,S}).
\]

各slot是独立预测，即使区间相同也不在此诊断中去重；一条GT只可匹配一槽。逐GT合法性必须实际验证，不把400可行外推到全2573。该上界按集合分别优化，不是不同集合可同时达到的联合上界，也不含类别正确性。

新C0命中由第6节计算。若`U9(334)−M_C0(334)≤0`，或400上oracle相对C0的视频等权改善连+5pp都不可达，则`REJECT / SCOPE_NOT_TESTABLE`，不训练、不再加槽。**不再要求旧合同下净恢复>167/334**。

### 3.2 原因第一环：原模型真的低读取吗

只用原预训练N的**最后一个decoder cross-attention层，全部heads平均、dropout前**权重，不能选择最有利层/头。对有效key中心以相邻中心中点划分时间单元，首尾裁到固定连续段；单元长度记\(\Delta t_t>0\)，总长L。网格不规则也使用同一定义。

对GT区间G，用时间单元与G的交叠长度比例积分：

\[
R(G)=
\frac{\sum_{q,t}A_{qt}|cell_t\cap G|/\Delta t_t}
{9|G|/L}.
\]

均匀时间读取为1；预设`R<0.5`为“相对自身时长低读取”。避免把短事件绝对注意力质量小当作异常。此量是读取系数代理，不是视觉信息量或语义解释本身。

在原334残余中，低读取比例的整视频bootstrap 95%CI下界须>0.50，才进入训练。否则`REJECT / UNDERREADING_NOT_ESTABLISHED`；不改阈值或换层。原400、163、长组及全组同时报分布，不作为重新选择成员的依据。

## 4. 唯一操纵的实现与预算

对每个decoder cross-attention层、每个head，保持原scaled logits \(s_{qt}\)，N原row-softmax；J求

\[
\tilde A=\operatorname{diag}(u)\exp(s)\operatorname{diag}(v),\quad
\tilde A\mathbf1=\mathbf1,\quad
\tilde A^\top\mathbf1=9w,\quad w_t=\Delta t_t/L.
\]

固定50轮log-space交替行列归一化，float32，不加温度、gate或可学习额外参数。仅valid keys进入求解，padding为0。每次前向的行、列相对边际误差≤1e−5；非有限或不收敛则TECHNICAL_FAILURE，不增加迭代凑结果。此容差检查新算子的数学实现，**不替代原生4e−6重建容差**。

若原生实际attention含无法维持此边际的query-specific硬mask，停止为接口不兼容；不能偷偷解除硬mask。原有位置编码、残差、self-attention、FFN、attention dropout位置均不改。记录平衡前后、dropout前权重；训练时保留原生dropout配置，两臂共享随机种子。

训练N/J×seed98/99/100，各500步。两臂同seed使用同初始权重、同batch顺序，冻结实体输入及encoder；训练同一decoder、query embedding、分类头和mask embedding。mask分支输入固定。AdamW，lr=3e−4、weight_decay=0、clip_norm=1，无scheduler/AMP；最终第500步，不选最佳checkpoint。

每步用原生Hungarian重新匹配完整事件；两臂算法和原分类、focal、Dice及辅助层权重完全相同，不继承095冻结事件—query分配。确切权重、loss reduction、背景权重从源配置读取并封存，不能恢复成095只训练末层的简化loss。无法核定原配置时走技术出口。

批次顺序沿用095的88个train批次ID；每个ID载入其完整pair target，不能仅载入当年匹配上的target条目。若完整target与记录的563GT不一致，停止查清来源，不自行补删。两臂每步相同有效序列，记录梯度/参数差，核验冻结encoder。一次资源估算无法容纳固定预算则停止，不删seed或减步数。

J归一化会增加计算，报告参数数、decoder耗时和峰值内存；本实验匹配更新步数和训练数据，不声称总FLOPs相等。未追加可训练容量，不能将计算开销隐去。

## 5. 同权重撤回与操纵回执

每个J最终checkpoint：正常J推理；仅归一化切回N做`J→N`；恢复J。输入、权重、候选容量不变，不新增训练臂。

恢复J与原J须满足4e−6、类别、区间完全一致。J的列平衡会按构造提高低读取区域的R，**这仅是操纵回执，不能单独当作机制阳性**。同权重撤回属于分布变化，损害本身也不够；必须同时通过训练N对照、类别加权集合时间分数的局部可分性和区间指标。

## 6. 预测封存、匹配与指标

先对评价pair生成所有9个query的mask、全类别概率、当前H区间并封存。推理不读取GT时长、谓词或400/334成员身份。然后连接GT，仅用于以下评价。

**时间形状主指标**：在S内按固定pair连续段，预测与GT建边`tIoU≥0.5`。先最大化一对一匹配数，再最大化总tIoU；余下tie按GT ID、query索引字典序。一个slot最多命中一个GT。各组独立匹配，结果不能跨组相加；全2573另作一次完整匹配，不能给334优先权。固定成员没有对应合法输出仍记失败。

**类别一致伴随指标**：每query先对包括背景的全部类别取argmax，tie按类别ID；背景则无前景候选，非背景保留该一个类别。再要求谓词一致+tIoU≥0.5作同样匹配。主体/客体固定，本指标不代替轨迹vIoU官方评价。全2573另报`命中数/非空前景候选数`的诊断precision，候选分母不得按GT过滤；无候选precision定义0。

每seed每组报告：N、非空候选数、命中、新增、损失、净差及匹配ID。计数改换匹配带来的新增/损失可能互相抵消，净差和完整匹配同时保留。

**局部分数指标**：在GT连接前，对所有谓词生成
\[
s_p(t)=\max_{q=1..9}P_q(p)\sigma(z_{qt}).
\]
这是固定集合聚合，不是GT时间择优query；不是最终检测器。评价时才取GT谓词p。正点为GT内，负点为左右各一个GT时长的邻域，排除其它同谓词GT，裁于固定段；坐标沿用087有效mask网格，不补点。无正或无负的事件列缺失账。各臂支持相同；400支持少于380条或20个视频，走`REJECT / INSUFFICIENT_SUPPORT`。该指标同时受类别和mask影响，只与区间结果联合解释。

**聚合**：400主指标、局部AUROC和1101长组均先视频内事件平均，再视频等权。N/J为三seed配对差平均；C0只一份，不能当3份独立样本。整视频配对bootstrap10,000次，seed98，百分位95%CI；同一次抽样保留所有seed/臂。334及全2573计数另用GT加权，并在视频重采样后重算分子分母。每项CI旁记录视频支持数。

**可达缺口修复规模**：令M为334的一对一时间命中数，
\[
\eta=\frac{\overline{M_J-M_N}}{U_9(334)-\overline{M_N}}.
\]
不截断负值；分母≤0时不定义，出口`REJECT / NO_RESIDUAL_HEADROOM`。bootstrap逐次重算U与M；若一次分母≤0，该次η保守记0并单列次数。η是新容量合同下的可达缺口闭合率，不是因果归因百分比，更不是恢复了多数全部334。报告U、N、J三个原始计数和绝对净恢复/334，禁止只报η。

## 7. 按优先级执行的互斥出口

1. **TECHNICAL_FAILURE**：材料/身份/数值/算子/梯度/完整预算/恢复一致性任一失败即停；不报科学阴性。
2. **REJECT / SCOPE_NOT_TESTABLE 或 UNDERREADING_NOT_ESTABLISHED**：训练前门槛不满足，即停。不是数据少就换群体。
3. **VERIFIED / SCOPED_INTERVENTION_CAUSE**：下列全部通过：
   - 400时间形状：J−N、J−C0视频等权差均≥+5pp且CI下界>0；三seed J−N均>0。
   - 400局部AUROC：J−N、J−C0均≥0.05且CI下界>0。
   - 334可达缺口η的CI下界>0.50；并完整报告绝对新增、损失、净恢复/334，不回填旧多数334门槛。
   - 400类别一致命中：J−N及J−C0的CI下界>0，防止只得到无正确谓词的短段。
   - 撤回：J−(J→N)的区间差CI下界>0；设D=AUC(J)−AUC(J→N)，I=AUC(J)−AUC(N)，D−0.5I的CI下界>0；恢复一致性通过。
   - 1101长组时间形状与类别一致差相对N/C0的CI下界都≥−1pp；全2573两种匹配的平均净命中均≥0，类别一致precision相对N/C0平均差≥0。
4. **REJECT（其余所有技术有效结果）**：
   - `DOWNSTREAM_EFFECT_BOUNDED`：读取平衡实现，但主要时间差CI上界<+5pp，或η上界≤0.50。
   - `METHOD_ONLY_NOT_CAUSE`：区间有收益但现象、AUROC、撤回或规模条件未共同成立。
   - `PROTECTION_FAILED`：长组或全组未通过。
   - `NOT_ESTABLISHED`：CI跨门槛、seed不稳、支持不足等；是本次停止决定，不是证明机制永不存在。

门槛为设计期的决策标准，未从098结果拟合。VERIFIED只支持：**“在这一冻结实体输入与相同9槽预算下，联合时间读取分配对主要可达残余具有可修复贡献。”** 不声称长关系语义压制、共存长度因果或所有短关系完整根因成立。REJECT后不加query、不调平衡强度、不改loss、不延长训练。
