# 086唯一后续实验设计：同一次前向的时间证据可读性

## 要回答的问题

在正确实体、完整共存输入不变时，短事件的局部时间证据在融合前已经难以读取，还是融合后才变难？这是079B尚未回答的问题；不把它叫已验证的长谓词压制。

## 同一个实验的三个对照

1. fine：最细尺度已投影256维、尚未加入粗尺度的特征。
2. fused：同一次原生前向的256维融合后特征。
3. position：同维纯时间位置基函数，检测位置/持续时间先验能否解释可读性。

三者各训练相同256→50线性头；训练数据、初始化、逐批顺序、500步上限、优化器、损失均沿用079B冻结配方。不是新检测架构，不训练编码器。输出所有谓词的逐时间分数，推理不输入GT关系类别或边界。标准化、类别权重仅由train估计。

具体为seed79、AdamW学习率0.001、weight_decay0.01、clip_norm1，三头同初始化、固定500步末checkpoint；不按dev选择。训练标签为所有同谓词半开GT区间在真实采样点上的并集；训练缺正或负支持的谓词不参与推断性评价，列出GT及视频损失，并留在400的覆盖账。500步相同不保证各层同等优化，保存梯度与loss，仅判定本固定训练配方的可读性。

position的256维中：前9维为`1,u,u²,sin(πu),cos(πu),sin(2πu),cos(2πu),sin(3πu),cos(3πu)`，其余为0；`u=linspace(-1,1,N_valid)`，N=1时u=-1。训练按原训练裁片有效长度，GT27按完整连续段有效长度归一化；padding不参与。沿用079B数学定义，解除旧helper仅接受N≤512的工程检查不能改变公式或截断。输入范围差异须明确列为诊断限制。

- 训练不引入GT27；评价不按GT时间裁剪，不改采样坐标，不用GT最优query、阈值、分量。

- 必须比较同批同设置的原生前向、hook前向和重复前向。仍按原先冻结数值容差及二值/类别一致性检查；最后单pair批次也必须通过。技术失败立即停，不放宽容差、不删批次。

## 只设一个主终点：局部时间可分性

对每条目标GT，在完整预测序列上，比较目标内部采样点与两侧邻域的目标谓词分数，计算AUROC；不是从图里找一个最高峰。邻域宽度固定为该GT时长；只用于评价定义，不能传给模型。去除邻域中其它同谓词已标注事件占据的点，防止把真实重复事件当负例。不要求其它谓词消失。

精确定义：GT为半开区间[a,b)，L=b−a；有效采样帧`t=origin+4i`。正点满足a≤t<b，负点满足a−L≤t<a或b≤t<b+L，并限制在固定连续段中、排除同谓词全部标注并集。使用原logit，AUROC为所有正负点对中`1[s_pos>s_neg]+0.5*1[s_pos=s_neg]`之和除以`N_pos*N_neg`。不扩展到整格、不开平滑、不同层使用完全相同点集。

没有内部点或没有剩余邻域点的GT标为不可评价，公布人数及视频数；不得以分数或命中结果删样本。邻域未标注仍不保证真实语义不成立，结论限于标注边界可读性。

逐视频先平均事件AUROC，再视频等权；主对比fine−fused。fine−position、fused−position是解释门槛，避免弱于位置先验却称语义信号。冻结seed、视频bootstrap 10,000次；同时报告全体与长关系的同口径，避免只看失败短组。

建议的事前最小有效差为AUROC 0.05，整视频95%区间下界>0，并至少20个有效视频、100条有效目标。**这是待执行的小试决策阈值，不是已观察结果或统计功效保证。** 有效样本不足直接未决，不更改组定义凑数。

辅助输出只用于解释：完整逐帧分数、原生mask诊断。若报固定0.5阈值区间，使用同谓词最高平均logit的连续分量（tie依次短区间、起点早），保留min5，末采样帧+1；禁止沿用079B evaluate用GT挑最佳分量的规则。报告新增/损失及端点误差，不用它替换主终点，不宣称新mAP或Top100召回。

## 判决与kill criterion

| 结果 | 允许的判断与停止动作 |
|---|---|
| fine−fused和fine−position均达到上述门槛 | 支持在**本冻结线性训练配方**下两层局部时间可读性不同；不宣称融合不可逆丢失信息或长谓词语义干扰，不能排除优化难度差异 |
| fused−position达门槛，而fine−fused区间上界低于0.05 | 在该人群、本配方上不支持≥0.05的fine优势，停止本配方的融合损害解释与扩训；不排除其他读出或其他优化下的差异 |
| fine−position、fused−position的区间上界均低于0.05 | 停止这一冻结线性读出配方；不推断所有小读出无效或视频无信息，不扩大训练 |
| 区间太宽、样本不足或方向不稳 | 机制未决，结束这一版本；不增加步数、随机种子、阈值搜索来追求阳性 |
| 技术一致性失败 | TECHNICAL_FAILURE，未回答科学问题；保留日志停止 |

本实验测量的是可读性，不是全面信息论独立性。fine胜出也不能单独证明特定长关系语义造成损害；不会自动生成颠覆性方法或进入全量训练。
