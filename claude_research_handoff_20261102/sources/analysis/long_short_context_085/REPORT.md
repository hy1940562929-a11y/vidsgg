# 085：外部长关系上下文是否压制短关系

日期：2026-10-20。冻结原 VrdONE 权重，训练步数 0；AutoDL 推理耗时 6.68 秒。原始材料已导入本地，独立复核另见 `reviews/long_short_context_085_actual_review.md`。

**结论：本轮没有找到稳定的“长关系压制短关系”证据。发现了外部输入会影响短关系分数，但没有恢复时间命中，也没有证明替换操作成功去除了长关系信息。机制仍未决，不能写成已证实或已排除。**

## 做了什么

在已有正确实体输入的 27 视频中，筛选：

- 关系不足 3 秒，完整落在至少 10 秒的连续实体对支持区间；
- 同一实体对存在另一种持续至少 3 秒的关系，覆盖目标短关系至少一半；
- 短关系及前后 0.5 秒的输入完全不动；
- 找到远处的长关系片段 L，以及距离近似、改动幅度近似的对照片段 N；
- 用同一个来源片段替换 L 或 N 的视觉特征，位置、长度、几何输入保持不变。

四组为原输入、原输入复制、替换 L、替换 N。目标 query 由原输入的谓词分类分数选择，之后固定；没有用 GT 时间挑选主读出的 query。另报任何 query 的最佳时间匹配上界。

有 466 条进入初筛的长共存短事件记录，其中 11 条满足干预条件；按预定每视频最多 4 条，最终 7 条、3 视频。329 条缺少足够的对照/来源窗口，88 条缺少覆盖一半的不同长谓词，16 条无可用 L，16 条不满足距离匹配，6 条不满足替换幅度/不重叠条件；另 4 条因视频配额未入选。这些筛选数字不代表全验证集规模。

最初 prepare 因长度 N 与对照起点 N 重名而失败。v2 改名为 N_start；v3 加入原模型步长与最小区间长度断言后重新封存计划。错误发生于模型推理前，未根据结果调整筛选或判决规则。原版本和失败目录保留。

## 实际结果

| 检查 | 原输入 | 替换长关系片段 L | 替换对照片段 N |
|---|---:|---:|---:|
| 固定 query 的时间命中（tIoU≥0.5） | 0/7 | 0/7 | 0/7 |
| 相对原输入新增／损失 | — | 0／0 | 0／0 |
| 任意 query 最佳时间命中上界 | 0/7 | 0/7 | 0/7 |

替换 L 后，目标区间 mask 分数在 4/7 条中上升；相对替换 N 也有 4/7 条更高。这只能说明存在输入敏感性，不能只挑这些上升样本宣称成功。

预定主指标按视频等权平均：

| 指标 | 结果 |
|---|---:|
| 目标 mask 概率：替换 L − 替换 N | +0.003202 |
| 95% 视频 bootstrap 区间 | [−0.006746, +0.022315] |
| 目标 mask 概率：替换 L − 原输入 | +0.005869 |
| 逐事件等权的 L − N（补充） | −0.002371 |
| 视频支持 | 3，未达到预定至少 10 个 |

以上是 mask 概率分数单位，不是召回率。主指标未达到预定 +0.01，置信区间跨零，视频支持不足，故未通过支持门槛。三个视频的 bootstrap 只作描述，不提供可靠总体推断。视频加权与事件加权异号也显示结果不稳定。

**操纵检查尤其重要：替换 L 后，原 L 区间的长关系 mask 分数只在 2/7 条中下降，逐事件平均反而上升 0.004026。** 因而不能把此操作称为“成功移除了长关系”。几何特征保持不变，而这些长谓词主要是 in_front_of、behind、next_to；保留的几何仍可能携带关系信息。这个解释也是待检验解释。样本只有5个实体对，6条watch与1条speak_to，不代表一般关系分布。

例如 `0049_3151715056` 的 watch [531,558) 与 next_to 共现：替换 L 后目标 mask 概率从 0.178278 到 0.202581，对照为 0.180266，但时间 tIoU 三组都为 0，长关系 mask 分数反而从 0.869705 到 0.881175。这个分数上升案例不支持“长关系减弱后释放短关系”。

## 与已有证据合起来看

- 082 全 val 固定读出：长共存短关系中，未标注重叠长关系的组时间漏检为 98.49%（261/265），有不同重叠长关系的组为 98.57%（2750/2790）。两者都困难；不是官方一对一召回，不是匹配后的因果比较。
- 080 控制结果并未支持稳定的正向长短竞争差异；073 历史替换实验也没有支持预期的记忆干扰。
- 079 削弱粗尺度路径没有取得总体收益；完全移除明显变差。粗尺度路径不是长关系语义本身，不能据此证明长压短。
- 085 新增了目标输入固定的真实干预，但得到的只是小样本分数敏感性，没有定向时间恢复。

**当前可以成立的研究表述：长期共存实体上的短事件时间定位困难。不能升级为：困难已经被证明由长关系压制造成。**

## 下一步边界

本轮不增加训练、不根据效果挑阈值、不放宽入组重跑。若继续验证长关系机制，先解决两个问题：有足够视频的可比干预，以及能实际降低长关系证据、又不破坏目标证据的操纵。操纵检查未通过之前，继续堆“抑制长关系”模块没有机制依据。
