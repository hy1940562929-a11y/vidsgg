# 091 架构草稿：事件时间质量与几何一致的区间决策

日期：2026-10-20。候选：`M091-EVENT-MEASURE`，对090的定向修订。状态：**`DESIGN_ONLY / UNVERIFIED / NOVELTY_UNCERTAIN`**，没有采纳为正式方法。

**用户硬标准**：先广泛调研，再针对实验确认的原因给出架构；不能用小模块堆叠替代机制。本轮已完成[26项文献对齐](../../literature/short_interval_cause_arch_091_survey.md)，但原因尚未实验确认，因此这是**条件性架构草稿**，不是已满足最终硬交付。

## 1. 设计针对什么

唯一目标是[CAUSE_STATEMENT](CAUSE_STATEMENT.md)中的假设：固定事件query后，原mask监督对同等错误质量的时间排列不敏感，是否留下了可修复的短区间错位/碎裂？

目前可以引用的是334/347残余失败、九query H/C库仅54/400至少一库匹配，以及分数优于位置null；不能把这些数字改写为损失缺陷已证实。VrdONE已有独立事件mask、实例匹配和Dice，故本方案**不以“首次事件建模”作为出发点**。

## 2. 一条完整的数据流

```text
视频 → 原实体轨迹与pair输入
     → 原时序编码器：X ∈ R^(T×D)
     → 原Q个事件query：h_q ∈ R^D
       ├─ 原类别/背景预测：c_q ∈ R^(K+1)
       └─ 时间质量预测：ρ_q ∈ R^T，ρ≥0，Σρ=1
                     ↓ 同一时间距离下的合法区间投影
                  I_q=[a_q,b_q)
                     ↓ 保留类别/存在性及原候选预算
                (subject, predicate, object, I_q, score)
```

**替换的核心是“时间输出变量—训练风险—区间决策”这一个整体契约**，不是在原mask之外再接起点头、终点头、gate或新query选择器。原实体输入和时序编码器可以复用，以免把上游改变混进原因解释。

| 部件/产物 | 功能 | 为什么对准该原因 |
|---|---|---|
| 原pair表示$X$、query $h_q$ | 保留现有视觉证据与实例身份 | 不把收益解释成增加输入或更换实体 |
| 时间质量$\rho_q$ | 表达这次事件的质量在整个有效时间轴上如何分布 | 直接保留位置与分布形状，供时间距离计算 |
| 实例CDF监督 | 惩罚质量移离GT的距离，按GT时长度量相对代价 | 区分原focal/Dice无法区分的部分同错误量排列 |
| 同几何区间投影 | 从完整分布得到一个合法连续区间 | 避免训练看整份分布、推理只看阈值首末点或低阶矩的脱节 |
| 原类别/背景与容量合同 | 决定是否输出、输出哪种关系 | 单位质量不能给空query凭空制造事件；不靠多输出获益 |

各query之间允许时间重叠：不同谓词或重复实例不被强制分割成互斥序列。这沿用集合实例预测能力，不是新的多事件能力声明。

## 3. 时间表示、监督与推理

### 3.1 原生输出变量

用原时间分支产生$z_{qt}$，令$p_{qt}=\sigma(z_{qt})$，再在有效位置归一化：

$$
\rho_q(t)=\frac{p_{qt}}{\sum_{j\in valid}p_{qj}}.
$$

实现采用稳定的`logsigmoid(z)`后softmax，避免所有$p$下溢。091统一使用该定义，以与因果干预共享概率变量；090的`softmax(z)`不混进同一次实验。

对GT区间$I$，目标是它在当前采样网格上的均匀单位质量$U_I$。**单位质量只定义事件的位置/形状，不表示存在概率，也不自动产生短长公平**。全视频低概率背景的累计质量可能仍影响分布，必须通过监督解决，不能靠定义宣布其消失。

### 3.2 监督

保留已有query—实例一对一身份合同；每个事件的时间主目标为：

$$
L_{\mathrm{geometry}}(q,I)
=\frac{W_1(\rho_q,U_I)}{\max(d_I,\Delta t)}
=\frac{\Delta t\sum_{k=0}^{T-2}|F_{\rho_q}(k)-F_{U_I}(k)|}
       {\max(d_I,\Delta t)}.
$$

类别/背景继续有相应监督；未匹配query不强迫对齐一个虚构事件。GT时长仅在训练中做相对误差归一化，推理不读取时长、GT谓词或目标边界。

完整候选架构将几何作为时间主目标，不再以阈值mask作为最终输出合同。**决定性实验先保留原mask项、只干预附加几何方向**，目的是隔离原因，而非声称“加一个loss就是最终新架构”。即便该实验阳性，也不能把尚未训练的完整替代架构标成有效。

冻结训练匹配用于机制识别；完整模型原有动态匹配的处理仍沿用基线，不在091引入新匹配机制。原因实验不能验证动态训练的全部行为。

### 3.3 几何一致的解码

合法网格区间集合为$\mathcal I$，每个query只输出：

$$
\hat I_q=\arg\min_{J\in\mathcal I}W_1(\rho_q,U_J).
$$

区间候选来自该输入段的全部合法网格端点，不使用GT。训练除以GT时长是样本加权；**推理不除以候选区间长度**，防止引入偏好长区间的捷径。

合法条件与历史口径一致：stride4，索引闭区间$[a,b]$映射`[frames[a], frames[b]+1)`，原视频帧长度至少5。并列依次选择较小起点、再较小终点。候选搜索只产生一个输出，不把所有搜索区间加入预测库。这个确定性解码不是GT oracle。

若$\rho=U_I$且$I$本身合法，则正确区间距离为0；短长均成立。单正采样点可能不满足min5，仍需投影扩展，不能声称精确恢复或删除该GT。对多峰分布，投影可能选折中区间；本设计没有证明能够解决所有重复事件。

直接枚举$O(T^2)$个区间、每个计算CDF距离的朴素代价为$O(T^3)$；**不声称已经实现线性解码**。实现时应批量/前缀优化并验证与精确小规模枚举相同，实际长度和内存必须先估算。超出单次资源预算就停止交接，不能悄悄改成GT附近搜索或放宽协议。

### 3.4 为什么修订090的矩读出

090从均值和方差解析端点。远端少量质量$\epsilon$、距离$D$会对方差贡献约$\epsilon D^2$，可能让短区间变宽。W1使用线性距离，影响约$\epsilon D$；改用同一距离投影可以减少这类平方放大。

这是数学动机，不是鲁棒性实验结果；W1仍受远端质量影响，也不是已证明的tIoU最优决策。**本轮取消矩读出作为优先方案，不删除090历史文档和审查记录。**

## 4. 存在性、重叠与预算不能省略

最小实验固定原生H非空query槽的准入集合，A/B/S/Z各槽经P输出一个合法区间，原空槽仍空；固定F的381/400准入，其他19条仍留分母。query数量、分类、排序、pair输入均不变；同pair各GT复用同一预测。

完整架构的存在性仍由类别/背景决定，不依据归一化后的密度峰高判断“有无事件”。高峰可能仅表示事件短，并非更有把握；不能因此自动提高短关系排名。本轮不增加质量重排序模块。

保持原query数量会限制事件容量，但091不以更多query补救。若方法需要重建分类、检测或动态query才能奏效，就不能归因于本轮监督因素。

## 6. 唯一最小验证如何同时服务原因与架构

直接引用[CAUSE_STATEMENT §5](CAUSE_STATEMENT.md)的`E091-GEOMETRY-CONTRACT`，**不另立第二套实验**：

- A原监督、B真实时间几何、S保留错误量但打乱几何；三臂同一原时间分支、输入/匹配/参数/预算。
- 同一组checkpoint使用共同P读出，隔离真实几何监督的作用；C读出同时对照A/S和原零更新C0，检验收益是否已经体现在可用分数结构中。
- 超过原监督但未超过S：不能证明真实时间距离重要。
- 只在P下有改善：支持配套读出，不能宣布原监督已是根因。
- 通过限定受控干预效应门槛后，才有理由推进该架构；依然不把完整主模型性能视为已验证。
- 既报短关系净增，也报长关系损失、全体时间匹配、实际输出数及长度匹配null。新mAP需要完整检测回放，本轮没有结果。
