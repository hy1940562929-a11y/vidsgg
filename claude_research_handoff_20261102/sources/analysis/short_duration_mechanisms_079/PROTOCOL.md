# 079：寻找可以通过架构或训练改变的短关系失败原因

状态：PREPARED_NOT_EXECUTED。2026-10-19。当前只有协议、代码和软件检查，没有新模型结果。

## 研究问题

同一实体对持续存在时，短关系的时间证据为什么没有转化为正确事件？重点找可以改变的计算环节：输入采样、多尺度融合、表征读出、定位监督。将成像/标注限制与模型机制分开。每个结果必须回到一个具体干预，不把所有失败统称为“长关系压制”。

## 数学上为什么值得检查这四处

1. **采样：**间隔为Δ、事件长度为L，若只有事件内部才有可识别信号，均匀随机相位下至少采到一点的概率为`min(1,L/Δ)`。这是理想采样模型，不是实际召回公式；事件外也可能提供线索。A改变相位和真实采样密度检验这一环节。插值不增加原始观测，所以是必要对照。
2. **融合：**若局部平均窗口宽W，长度L<W的矩形变化幅度a会被平均成约`aL/W`。这解释“短暂变化可能被平滑”，不代表真实FPN就是平均滤波。A直接改变实际粗尺度注入；B用同容量读出衡量信息是否更难利用。短事件并不等于只有高频，不能仅凭频谱图就判定原因。
3. **训练：**对于逐时间点平均损失，事件内的项只占约`L/T`，但真实梯度还受误差、focal/Dice、匹配和权重影响。因此不能仅凭时长判定梯度不足；旧043归一化与075监督负结果继续保留。新C检验的是另一件事：优化区间分类概率是否等价于改善区间重合，使用`CE + E[1-tIoU]`直接干预目标。
4. **评价：**等长区间整体错位δ时，`tIoU=max(0,L−δ)/(L+δ)`。同样误差对短关系更严厉。因此除命中数外必须报告起止绝对偏差、相对偏差和平均IoU。正确GT实体输入中的时间IoU也不是原轨迹输入下的体积IoU。

**仍需单列的可改原因：**query数量/匹配、训练中的短样本配额、谓词分类和TopK评分。本包保持这些不变，用A的多种query口径与已有审计判断是否值得另立实验；没有实现“增query”“改训练配额”“新评分器”，不能在执行后声称已验证它们。只有原候选中存在正确时间输出的实例，才属于不新增候选的纯选择/排序可修复范围。

## A：采样和粗尺度路径的冻结模型干预

数据：已有strict27正确实体输入视频，历史共2,573条GT，非随机、已曝光的诊断子集。选择依据输入文件和冻结名单，不根据本次模型成败选择。

固定：原EMA权重、实体身份/框、完整连续共存输入、9个query、默认mask阈值。不得按GT关系起止裁剪输入。

| 臂 | 变化 | 作用 |
|---|---|---|
| native4 | 原步长4、offset0 | 本次同设备基线 |
| phase1/2/3 | 步长4、改变采样相位 | 检查关键观测错位及相位敏感性 |
| dense2 | 读取原逐帧ROI缓存，每2帧取一次 | 增加真实可用观测 |
| visual_interp2 | 使用dense2相同时间坐标和最后21维几何；前2048视觉维由native4插值 | 只隔离新增ROI观测，控制token数和几何 |
| full_interp2 | 全2069通道插值到dense2网格 | 额外敏感性，不作为纯视觉效应 |
| coarse_gate_half/zero | native4输入；最细FPN的粗尺度注入乘0.5/0 | 直接干预架构中的粗细尺度融合 |

结构变化只在最细融合处：`fine + g * upsample(coarse)`。原始g=1。g=1的替换实现必须和原forward通过no-op核验；两种干预值都报告，不能读完结果选最优值。冻结干预不是新模型训练完成，也不证明特定长谓词语义干扰。gate同时改变特征幅度和后续归一化输入；若未来进一步归因粗尺度的特定内容，还需幅度/扰动强度匹配的对照。

重要实现契约：改变stride会改变loader中的相邻bbox差分，所以dense2与visual_interp2的几何必须逐元素相同。插值使用真实帧坐标，尾端采用边界值保持并记账。推理保留全序列，原生padding规则保持；不将长输入截为512。区间解码为最后正采样帧+1，最小跨度始终按原视频5帧计算。不同臂按实体段和共存区间绑定，不能按row index绑定。

指标：逐GT任意query时间候选覆盖、谓词条件覆盖、固定非时间oracle选择的时间输出；二值mask与hull指标分开。二值占用采用原帧坐标forward-hold：每个采样点保持至下一采样点，最后一格截到共存结束。它是079新增明确口径，不直接与历史GT27二值指标混算。所有GT留在总分母，缺输入/资源超限单列；另报共同实体段支持上的对照。短于1秒、1–3秒、3–10秒、至少10秒、全体、共存至少10秒且关系短于3秒。每个对照必须有新增、损失、净变化，按视频配对bootstrap。

预期模式与判断（不是预测数字）：

- dense2超过visual_interp2且超过native4：支持新增观测有价值；若只超过native4而不超过插值，不归因于真实观测。
- 两个粗尺度削弱臂都改善短组，且细尺度probe更好：支持当前粗尺度注入路径是可干预因素。长组下降说明存在取舍，不是总体有效。
- 原始输出变了但时间覆盖没改善：有敏感性、无收益。
- 默认短组净改善达到1个百分点且视频配对95%区间下界大于0才记为强支持；1个百分点只是事前小试筛选门槛。支持视频不足10、区间跨0或两gate方向不一致记INCONCLUSIVE。所有臂都无稳定净收益时，不加密到stride1、不搜索更多gate追逐阳性。

本轮A的覆盖指标不是官方R@100。即使A阳性，也必须再用原实体输入和固定Top100验证；当前包不自动扩大到全benchmark。

## B：同容量读出检查时间证据在哪一步变得难以使用

使用官方training来源的既有32视频训练、8视频开发，继承010固定pair/crop/随机采样；原checkpoint预训练可能见过开发视频，这不是独立测试集。GT27不进入probe训练或配置选择。

真正的backbone特征是512维，不能与256维FPN直接称等容量。本轮比较：

1. `neck.lateral_norms[0]`输出：最细尺度已投影到256维、尚未加入粗尺度。
2. `neck`最终256维mask特征：完成多尺度融合。
3. 同容量position-only对照：时间位置基函数，其他输入维为零。

同一256→50线性头、相同初始化/批顺序/500步/训练标签；标准化与类别权重只从train拟合。输入不包含GT起止。根据完整同pair谓词标注构建union，censored pair排除且记录。未标注位置仅称annotation-negative，不称真实关系不存在。

读出冻结编码器，只训练小probe。特征只提取一次并缓存，不为每一臂重复跑backbone。

指标：按谓词帧级判别、按事件的连通区间覆盖、起止误差、同谓词时长分层、视频配对区间；只在训练有支持的谓词上评价泛化读出并报告剩余分母。

预期模式：fine明显优于fused且超过position，支持融合前的标注时间更容易被同容量读出；不证明信息论意义上的信息消失。两者相当则不支持此定位；两者都不超过position则probe不给机制结论。若A的结构干预也不改善，则不以B单独的差距启动新架构训练。

## C：相同区间头，只改变监督目标

复用原078的joint SpanHead作为共同结构；所有臂相同初始状态、固定匹配、样本顺序、500步、seed79、优化器和解码。区别仅为CE vs CE+期望区间IoU风险。原mask和零更新区间作为锚点报告。不是把soft-mask Dice改名为IoU，也不再次训练078的hard/random邻域方案。

新增目标：对合法起止区间分布，计算真实帧坐标下的`E[1-tIoU(pred_interval, GT)]`，系数固定1。`end=origin+stride*last+1`，不能把采样格点IoU当作真实帧IoU。训练用GT监督合法，推理时只看模型分数。

训练/开发：原043缓存32/8视频、563/169保留GT。单采样点无法进入该span损失时，单列排除但保留总评价分母。只评价固定GT匹配query的定位诊断，不称官方召回。

预期模式：CE+IoU比CE有更好的实际区间重合和短关系净命中，且超过初始锚点；不能以自己的loss更低作为支持。该干预也改变梯度尺度和方向，保存裁剪前梯度范数与裁剪频率；当前未设等梯度强度对照，阳性仅支持此监督配方，不独自证明历史失败全部由CE错位导致。

停止与扩展门槛：相对CE、原mask、零更新区间三个锚点分别要求train、dev短关系均有净新增，dev总体和长组不下降；同时报告平均IoU与端点误差，才获得后续原输入128视频验证资格。任一门槛未过，结束该版本；不自动追加step、seed、阈值或模型。该资格不是方法通过，128验证代码和正式方法另行决定。
