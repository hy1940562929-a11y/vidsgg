# M097：实例条件化的局部状态比较读出

日期：2026-10-20。**DESIGN_ONLY / UNVERIFIED / NOVELTY_UNCERTAIN**。未采纳为正式方法，未训练。M091几何主配方停止。

## 1. 核心变化

原流程：

`实体对时序特征 → 时序编码ft；关系query hq → 判别向量wq；wq·ft → mask分数 → 区间`

候选流程：

`同一冻结ft → 当前状态 + 左右邻域状态 → 与hq共同进行条件比较 → 关系成立分数 → 原固定区间读出`

query仍表达实例/谓词相关语义；每个时刻的关系成立判断同时查看当前状态和附近的状态。目标是改变**最后决策的信息依赖方式**，不是再给同一个点积分数加时间距离损失。编码器、轨迹、分类、query选择和输出数量不在本轮改动内。

## 2. 三个组成部分

| 部分 | 输入→输出 | 作用及可检验预测 |
|---|---|---|
| 同pair状态参照 | 完整连续段`ft`→左右固定邻域均值 | 提供“相对附近状态有什么不同”；不从GT找背景，不先裁短事件 |
| 条件比较算子 | `hq, ft, ft−左均值, 右均值−ft`→每时刻logit | 非线性地联合判断当前语义和状态变化；正确对齐应比错位参照有效 |
| 固定成段 | 原H准入＋sigmoid分数→一个合法连续分量 | 继承095外部冻结准入及旧C，未准入保持空，使收益不能靠多给候选名额 |

VrdONE已经有局部和全局时序编码；这里不是首次引入时间上下文。变化发生在最终query—时间状态决策上。原点积也可能完成此判断，故必须先实验。

## 3. 最小实现：用可归零的比较器验证架构思想

在原生未标准化特征上计算并冻结`z0(q,t)`；另用train统计标准化后的`f̃t`构造局部差分`dt`：

`z(q,t)=z0(q,t)+vᵀ GELU(Wh hq+Wf f̃t+Wd dt+b)+β`。

固定隐藏宽度32，`hq`256维、`f̃t`256维、左右差分拼接512维；参数数为
`32×256 + 32×256 + 32×512 + 32 + 32 + 1 = 32,833`。
`v=0, β=0`，起点严格复现原分数。只训练这个比较算子；原mask embedding也冻结。

残差写法用于保证零更新对照相同；架构主张是把最终可分离点积读出改为依赖邻域的条件判别。**这个小比较器本身不足以称“颠覆性创新”**。它先回答这种新的依赖关系是否必要，不能用模块名称代替机制证据。窗口、路由、损失、预算和停止规则见[唯一合同](EXPERIMENT_CONTRACT.md)。

## 4. 与近邻的关系

| 近邻 | 已经做了什么 | 本草案可以和不可以主张什么 |
|---|---|---|
| VrdONE | 局部/全局时序编码，query分类与时间mask | 可以检验固定其表征后的读出条件性；不能说其没有局部时间证据 |
| DyFADet | 时间位置相关的动态特征聚合和动态检测头 | **最接近的创新性威胁**；动态头、适应不同时长本身都不是新意 |
| ContextDet | 自适应上下文聚合服务时间定位 | “附近上下文更有用”不是新意；需要具体关系实例、同源控制与错误机制证据 |
| CondInst / SeqFormer | 实例条件化动态mask；视频实例级query与逐帧信息结合 | query条件化、实例动态参数不是新意；不能把一个视频query本身定为缺陷 |
| Mask2Former | masked attention聚合局部特征，query mask预测 | 点积/掩码类读出可以成功；反对“这种形式必然不能定位短事件”的泛化 |

来源、阅读层级及其它监督路线见[097文献表](../../literature/short_interval_cause_arch_097_survey.md)；091的26项背景继续作为历史调研，不将它们全算成097新读全文。

## 5. 可能贡献与当前边界

若唯一实验通过，潜在贡献是：在固定实体输入、固定语义query和固定预测容量下，识别并修复**局部状态对照使用不足**这一操作性机制。需要真实邻域相对同参数错位/全局对照的优势，以及同权重撤回与恢复证据。

目前缺少这些证据；也没有全量benchmark、新数据集或独立泛化结果。仅把DyFADet式动态头搬到VrdONE，不能自动构成CVPR级创新；若实验只显示一般容量收益，主原因与该架构叙事均不接纳。

本轮不新增事件数预测、多尺度融合、gate、query重选或新的几何损失；不据此排队训练。
