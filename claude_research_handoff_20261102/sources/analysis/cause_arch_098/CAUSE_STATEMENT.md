# H098：事件查询的时间证据读取分配不足

日期：2026-10-20。**DESIGN_ONLY / NOT_RUN / NOT_VERIFIED_CAUSE**。
本轮只提出一条原因假设、一份决定性合同和对应架构草稿；不运行实验、不连接服务器、不改RQ、不采纳正式方法。

## 1. 先处理容量墙：明确选择A

**在继承旧读出容量约束（旧F / 原H准入 / 每slot至多一个合法区间）时，任何要求“多数净恢复334”的原因配方都会先撞容量墙。** E097的GT-oracle最大净恢复为149/334，低于167/334；换一种损失或比较器也不能突破同一输出合同。

本方案选择 **A：同时改变所有对照的诊断读出假设**，不把旧F复用造成的冲突直接宣称为原生模型的主要原因。

- 原生VrdONE每个pair已有9个query。本轮让原模型和干预模型都使用同一固定pair的9个自然输出；每query最多一个区间，总槽位数不增加。
- 旧F不再决定主评价的query，原H的历史准入表不再冻结为空槽。各模型均按自己的当前分数、相同阈值和min5产生区间。
- 保留400/163/334/1101和全2573成员、固定实体输入、pair_idx及连续段；一对一匹配，不能一个预测重复计多个命中。
- 新基线必须在新合同下重评。**释放诊断限制本身的增益不算架构增益**；不得把新数字与095固定F的14/400直接相减。

这改变的是诊断中的事件输出机会和匹配合同，不是视频关系检测任务。主终点仍是时间形状诊断，并附类别一致指标；它不是官方mAP或Top100召回。完整规则见[唯一实验合同](EXPERIMENT_CONTRACT.md)。

## 3. 恰好一条新的完整原因假设

> **H098（未验证）：在长期共存的实体对中，独立归一化的事件query可能把读取资源重复集中到少数时间区域，使部分短事件所在时间的证据没有充分进入query状态；虽然模型接受逐事件监督，多个query最后仍不能形成这些短事件的时间mask。这个“跨query时间证据分配不足”是锁定残余群体中一个主要、可操纵的修复来源。**

完整待验证链条是：

`较长时间轴中的共享内容 → query合计读取集中 → 短事件相对其时长被低读取 → query状态缺少该事件证据 → 所有现有query的分数难成短段`。

“共享内容引发集中”尚无测量；本合同直接检验后面可操纵的链条。即使通过，也只能认定读取分配的限域贡献，不能证明“另一条真实长关系语义造成压制”，也不能证明共存时间本身是因果起点。

### 为什么不是重提旧配方

E091冻结query，仅改mask末层的监督，不能直接检验“证据如何进入query”。E097没有训练，容量门槛拒绝的是旧读出下的多数恢复目标。H098改动decoder的读取算子，并让两臂共享原生9-slot输出机会；不加距离损失，不沿用局部比较器，不搜query、不拆hull。

### 源码边界

归档源码的`predictor.py`先由decoder形成query状态，再生成类别与mask embedding；`maskvrd.py::bipartite_match`已用分类、focal、Dice代价作Hungarian事件匹配。**不能写VrdONE没有逐事件监督，也不能将其描述为每个实体对只有一个事件槽。**

源码：[predictor.py](../../handoff/incoming/VIDOR-NATIVE-FEATURE-027/partial_v4/results_v4/source_snapshot/models/predictor.py)、[maskvrd.py](../../handoff/incoming/VIDOR-NATIVE-FEATURE-027/partial_v4/results_v4/source_snapshot/models/maskvrd.py)。
本地已读快照未提供实际被调用的完整`local_transformer`实现。执行前必须核验attention接口、有效key与归一化；本轮不能声称已有可运行实现。

## 4. 唯一可操纵因素与数学含义

对某cross-attention头，原归一化为：

\[
A_{qt}=\operatorname{softmax}_{t}(s_{qt}),\qquad \sum_t A_{qt}=1.
\]

它不限制多个query合计的时间读取量\(\sum_qA_{qt}\)。H098并不声称它必然集中，而是认为实际失败群体出现了有害集中。

唯一干预：在同一Q/K/V、9个query和有效key上，将归一化替换为联合平衡，使行和仍为1、列和为\(9w_t\)。\(w_t\)是该key代表的有效时间单元长度占比；均匀网格时为\(1/T\)。不使用GT时间或谓词设定注意力目标。

这是对**读取资源**的干预，不是让mask概率均匀，不是要求预测覆盖整段，也不保证事件一定可识别。背景同样会分到读取量；均匀读取可能浪费资源或破坏合理的稀疏关注，这正是可能拒绝本配方的反例。

## 6. 什么才能升级，什么必须停止

唯一实验E098同时要求：原模型确有系统性低读取；操纵确实改变读取；类别加权集合时间分数的局部可分性及一对一短区间命中改善；在可达9-slot缺口上具有足够规模；同权重撤回/恢复符合预期；长组与全组保护通过。该分数同时受类别概率、query聚合和mask影响，不能单独证明原始mask可分性改善。具体数值门槛均在合同预设，不能事后修改。

通过的名称是`VERIFIED / SCOPED_INTERVENTION_CAUSE`：限于该输入、样本和预算，证明读取分配对主要可达残余有可修复贡献。**不等于所有短关系的完整唯一根因，不等于新架构已获CVPR级验证。**

若原低读取现象不存在，或读取平衡成功但短区间未获得预设改善，输出REJECT并停止本配方；技术条件不满足输出TECHNICAL_FAILURE。不给“再调一次平衡强度”留自动旁支。
